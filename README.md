# AI MATCH PRO — Android starter

واجهة أولية لتطبيق Android باللغة العربية (RTL) باستخدام Kotlin وJetpack Compose.

## التشغيل
1. افتح Android Studio.
2. اختر Open ثم مجلد `ai_match_pro_android`.
3. انتظر مزامنة Gradle.
4. شغّل التطبيق على محاكي أو هاتف Android.

## الموجود حالياً
- شاشة رئيسية للمباريات.
- شريط أفقي قابل للسحب لاختيار أي يوم من الأيام الـ15 القادمة.
- بطاقة لكل مباراة.
- صفحة تحليل تعرض خمسة اختيارات واحتمالات تجريبية.
- إذن الإنترنت مضاف تمهيداً لربط واجهة بيانات المباريات.

## مهم قبل النشر
المباريات والتوقعات الحالية بيانات تجريبية ثابتة وليست حية. يلزم:
- اختيار مزود بيانات مباريات وإحصائيات معتمد والحصول على API key.
- إنشاء backend آمن لحفظ المفتاح وعدم وضعه داخل تطبيق Android.
- جلب المباريات حسب التاريخ والدوري وتحديث النتائج الحية.
- بناء نموذج احتمالات يعتمد على بيانات فعلية واختباره تاريخياً.
- عرض مصدر البيانات ووقت آخر تحديث، وعدم تقديم الاحتمالات كضمان.

هذا المشروع نقطة بداية قابلة للتطوير، وليس APK جاهزاً للنشر.
